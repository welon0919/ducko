雖然市面上有很多成熟的工具（如 Hugo, Zola, Next.js），但我相信**「造輪子」**是學習程式語言最快的方式。透過這個專案，我學習到了：

1. Rust 的檔案系統操作 (`std::fs`)
2. 文字解析 (`pulldown-cmark`)
3. 模板渲染 (`Tera`)
4. 並發與多執行緒 (`Tokio`, `std::thread`)
